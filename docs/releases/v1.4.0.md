# نسخهٔ 1.4.0 — مهارت‌های هماهنگ‌کننده و Git/Release

- افزودن `task-orchestrator` برای انتخاب skillهای مرتبط، اجرای کامل درخواست و بررسی معیار پذیرش با context مختصر.
- افزودن `git-release-sync` برای ثبت تغییرات، هماهنگی نسخه، push و Release مجاز با حفظ تاریخچه و بررسی commit منتشرشده.
- مجموع ده skill قابل ترکیب؛ نصب انتخابی و سراسری برای Codex، Claude Code، Cursor، Antigravity، Gemini CLI، Copilot، OpenCode، Windsurf/Cascade، Cline و Roo Code.
- راهنمای فارسی نصب، مثال تکی/ترکیبی، مشارکت، امنیت، مجوز و تغییرات.
- شامل بهبودهای منتشرنشدهٔ 1.2 و 1.3: installerهای امن‌تر، مسیرهای native، تست global در مقصد موقت و اصلاح Bash قدیمی macOS.

## نصب

<div dir="ltr">

```powershell
./install.ps1 -GlobalOnly -Agents all -Skills all -WhatIf
./install.ps1 -GlobalOnly -Agents all -Skills all
```

</div>

<div dir="ltr">

```bash
bash ./install.sh --global-only --agents all --skills all --dry-run
bash ./install.sh --global-only --agents all --skills all
```

</div>

نصب سراسری برای حساب محلی است؛ به session ابری خودکار منتقل نمی‌شود. راهنمای کامل در `docs/global-installation.md` و مثال‌ها در `docs/skills.md` قرار دارد.

## ارتقا و بازیابی

ابتدا dry-run و diff را بررسی کنید؛ برای جایگزینی فایل اختصاصی از Force استفاده کنید. نسخه‌های قدیمی و بلوک‌های همیشه‌فعال به‌صورت خودکار حذف نمی‌شوند؛ راهنمای مهاجرت را بخوانید. backupهای یکتا برای بازگرداندن فایل‌های قبلی باقی می‌مانند. نصب جدید به معنی deployment پروژه نیست.

## اعتبارسنجی و محدودیت

تست‌های installer و CI نتیجهٔ اجرایی ثبت می‌کنند؛ ساختار SKILL.md با اعتبارسنج بررسی می‌شود. discovery و کیفیت پاسخ در همهٔ نسخه‌های تمام agentها آزموده نشده است. اندازهٔ context و نتیجهٔ نهایی به مدل، دامنه و شواهد بستگی دارد؛ حداقل مطلق توکن یا نبود همهٔ باگ‌ها تضمین نمی‌شود.
