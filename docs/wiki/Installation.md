# نصب، ارتقا و بازیابی

مرجع واحد دستورهای Windows/Bash، دریافت ZIP/Git، نصب پروژه‌ای/سراسری و backup در [راهنمای نصب](../installation.md) است. مسیرهای native هر agent در [جدول نصب سراسری](../global-installation.md) آمده‌اند.

نصب پیش‌فرض هم پروژه‌ای و هم سراسری است؛ برای محدودکردن مقصد از ProjectOnly یا GlobalOnly استفاده کنید. ابتدا پیش‌نمایش را ببینید. `git pull` فقط checkout را به‌روز می‌کند؛ برای ارتقای کپی نصب‌شده، installer را نیز اجرا کنید.

پس از نصب، [تفسیر خروجی و پاک‌سازی امن](../post-installation.md) را بخوانید. checkout موقت و bootstrap با فایل‌های نصب‌شده متفاوت‌اند. backupهای واقع‌شده در Temp را پیش از پاک‌سازی Temp حفظ کنید. فایل `.path` در backup جدید PowerShell، مسیر اصلی را ثبت می‌کند.
