# Wiki محلی بستهٔ ممیزی و اسکیل‌ها

این پوشه پیش‌نویس محلی Wiki است؛ Wiki checkout مستقلی پیدا نشد و هیچ صفحه‌ای روی GitHub Wiki منتشر نشده است. لینک‌های نسبی برای همین ساختار repository نوشته شده‌اند؛ هنگام انتقال به Wiki مستقل، مسیرهای آن‌ها باید تطبیق داده شوند.

- [نصب و بازیابی](Installation.md)
- [استفاده از اسکیل‌ها](Skills.md)
- [معماری و نمودارها](Architecture.md)
- [فهرست اصلی مستندات](../README.md)

بستهٔ فعلی یازده اسکیل دارد و `VERSION` برابر `1.5.0` است؛ تغییرات در changelog ثبت شده‌اند. tag قدیمی `v1.4.0` این تغییرات را ندارد. نسخهٔ کد و آخرین GitHub Release را یکسان فرض نکنید.

برای شروع، بسته را در مقصد موردنظر نصب کنید، سپس نام اسکیل و دامنهٔ کار را در پیام بنویسید. [راهنمای نمونه‌های استفاده](../skills.md) و [project-builder](../project-builder.md) مرجع جزئیات هستند.
