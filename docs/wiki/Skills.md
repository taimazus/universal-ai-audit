# استفاده و ترکیب اسکیل‌ها

نسخهٔ [انگلیسی راهنمای اسکیل‌ها](../skills.en.md) و [ترکیب‌ها](../combinations.en.md) نیز موجود است. ترتیب راهنما از هماهنگی و ساخت تا بررسی، اصلاح، پاک‌سازی و Git است؛ مراحل اجباری نیستند. موضوع جدید به‌طور پیش‌فرض fa/en و زبان اضافی ورودی است؛ به‌روزرسانی همهٔ ترجمه‌های موجود موضوع را پوشش می‌دهد و جهت و تراز مطابق زبان اعمال می‌شود.

برای کاربرد و نمونهٔ کامل هر بیست‌ویک اسکیل، [راهنمای اسکیل‌ها](../skills.md) را بخوانید. برای workflow ترتیبی و انتقال ledger، [راهنمای ترکیب‌ها](../combinations.md) مرجع است. ترکیب اسکیل‌ها به‌تنهایی اجرای چند agent یا مجوز انتشار ایجاد نمی‌کند.

برای شروع از یک موضوع و ساخت پروژه با پرسش‌وپاسخ، [project-builder](../project-builder.md) را انتخاب کنید. برای هماهنگی کار موجود از task-orchestrator استفاده کنید؛ برای فقط ممیزی یا PR، اسکیل مرتبط را مستقیماً انتخاب کنید. همهٔ اسکیل‌ها لازم نیستند.

گزارش‌های ممیزی باید شواهد، شدت، محل دقیق و تست تأیید داشته باشند. «ریسک» و «فرضیه» با نقص اثبات‌شده متفاوت‌اند. وضعیت اصلاحات این repository در [گزارش ممیزی](../audit-report.md) موجود است.
