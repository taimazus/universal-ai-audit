# Security Policy

## Supported version

Security fixes are targeted at the latest published release and the current `main` branch.

## Reporting a vulnerability

Please avoid publishing exploit details, credentials, tokens, private repository data, or other sensitive material in a public GitHub issue.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If private reporting is not enabled, contact the maintainer through an appropriate private channel listed on the maintainer's GitHub profile and provide only the minimum information needed to establish contact before sharing sensitive details.

A useful report includes:

- affected version or commit;
- affected installer/adapter/platform;
- reproduction steps;
- expected versus observed behavior;
- impact assessment;
- suggested mitigation, if known.

## Scope

Relevant reports include unsafe installer behavior, destructive configuration replacement, command injection, privilege-boundary problems, secret exposure, unsafe generated paths, or other vulnerabilities in this repository's code and distribution artifacts.

Third-party AI agents and their services are outside this project's direct security boundary; vulnerabilities in those products should also be reported to their respective vendors.
